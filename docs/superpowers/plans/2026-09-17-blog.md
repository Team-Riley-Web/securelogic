### Task 1: Replace the blog index hero

**Files:**
- Modify: `src/pages/blogs/index.astro`

- [ ] **Step 1: Swap the hero**

In `src/pages/blogs/index.astro`, replace the `import PageHero from
'../../components/PageHero.astro';` line with `import SectorHero from
'../../components/sector/SectorHero.astro';`, and add `import contactBg from
'../../assets/images/contact-bg.jpeg';` near the other imports. Replace the
`<PageHero .../>` call with:

```astro
      <SectorHero
        eyebrow="Blog"
        headline={['Genesis360', 'Blog.']}
        support="Tips and insights on botanical disinfectants, Genesis360 dry fog systems, indoor air quality, and microbial risk reduction."
        poster={contactBg}
        cta={{ href: '/get-a-quote/', label: 'Get A Quote' }}
      />
```
View `src/assets/images/contact-bg.jpeg` with your Read tool and judge
whether it reads well cropped into a wide hero. If it doesn't (too tightly
framed, an odd crop, etc.), pick a different existing brand still instead —
check what's already imported by other sector pages for options (e.g.
`faq-room.jpg`, `human-fogger.png`) and use whichever reads best; note which
one you chose and why in your report.

The rest of the file (`const [featured, ...rest] = posts;`, the featured-post
block, the grid, the closing `QuoteForm` band) is untouched. This page must
still use `x-data`/`x-init` for the reveal system the way every `SectorHero`
consumer does — check whether the file's outer wrapper already has
`x-data x-init="document.documentElement.classList.add('reveal-enabled')"`
on its `.bl` div (the ag/Human/HVAC pages all do); if it's missing, add it,
since `SectorHero`'s internal `reveal`-class elements need it site-wide.

- [ ] **Step 2: Build and assert**

```bash
npm run build 2>&1 | grep -i "error\|page(s) built"
node scripts/assert-html.mjs dist/blogs/index.html "Genesis360" "Blog." "Tips and insights on botanical disinfectants" "How to Identify Sick Building Syndrome"
grep -c "<h1" dist/blogs/index.html
echo "dollar figures: $(grep -oE '\$[0-9]' dist/blogs/index.html | wc -l | tr -d ' ')"
npx astro check 2>&1 | tail -4
npm run check:brand
```
Expected: `43 page(s) built` (no route count change); four `ok` (the last
needle confirms the featured-post grid below the hero still renders — its
exact title may differ if `posts` has been reordered since this plan was
written; if it fails, use whatever the current featured post's title
actually is); h1 count 1; `dollar figures: 0`; `8 errors`; brand passes.
